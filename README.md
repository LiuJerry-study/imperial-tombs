# 帝陵图志 · 中国历代帝王陵墓地图

一张可以**按时代筛选、按片区规划行程**的中国帝陵地图。单页网页，打开即用，不需要安装任何东西。

![预览](https://img.shields.io/badge/帝陵-122%20处-a63a2e) ![时代](https://img.shields.io/badge/时代-11%20组-b08d57) ![路线](https://img.shields.io/badge/路线灵感-17%20条-2f7d6d)

## 快速开始

直接双击 **`index.html`** 用浏览器打开（Chrome / Edge / Firefox / Safari 均可）。

**在线版**：部署到 GitHub Pages 后访问 `https://<你的用户名>.github.io/imperial-tombs/`，部署步骤见 [DEPLOY.md](DEPLOY.md)。

- 默认「高德 · 混合」底图：低倍用矢量路网（清晰、有地名），放大到 15 级以上自动切换到卫星影像 + 标注——高德矢量瓦片在草原、荒漠、山地等无细节区域会返回空白瓦片，混用卫星可避免放大后白屏。
- 也可手动切换「高德 · 矢量」「高德 · 卫星」「OpenStreetMap」「无底图（离线可用）」；纯矢量模式下遇到空白瓦片会自动用同位置卫星影像补位。
- 断网也能用：切到「无底图」模式，仍可查看点位、筛选、编辑行程、导出。
- 底图为 GCJ-02，数据为 WGS-84，页面会自动做坐标偏移转换，因此点位与高德底图对齐。

## 功能

**看陵**

- 122 处帝陵 / 王陵 / 陵区，覆盖秦、两汉、魏晋南北朝、隋唐、五代十国、宋、辽金西夏、元、明、清、吐蕃。
- 按时代、开放状态、标签（世遗 / 5A / 国保）筛选，按陵名、墓主、地点搜索。
- 点击点位看简介、到访提示与坐标；低精度点位会标注「位置待考」。
- 缩放小的时候自动聚成气泡，点气泡放大。

**规划路线**

- 点「＋ 加入行程」把陵加入清单；行程支持上移 / 下移 / 删除、一键按直线距离优化顺序。
- 自动统计站点数、直线距离、估算公路里程、行车时间与建议天数。
- 17 条现成路线灵感（西安秦汉、咸阳原西汉九陵、唐陵东/西线、洛阳邙山、南京六朝、丹阳齐梁、北京十三陵、清东陵、清西陵、巩义宋陵、沈阳关外三陵、内蒙古辽陵、宁蒙西夏与成陵、成都前蜀后蜀、杭州绍兴吴越南宋……）。
- 导出：**复制行程文本 / GPX / GeoJSON / CSV**，或直接生成 **高德驾车路线** 链接。
- 行程与「打卡」记录保存在本机 `localStorage`，刷新不丢。

## 「所有帝陵」的覆盖口径

本图收录**中国历史上主要王朝与割据政权**的帝王陵墓，共 122 处，含：

- 正式帝陵（秦始皇陵、西汉十一陵、唐十八陵、明十三陵、清东陵/西陵等）
- 追尊陵（明祖陵、明皇陵、明显陵、北周成陵、唐惠陵/恭陵等）
- 陵区（东汉邙山帝陵区、西晋帝陵区、北魏邙山陵区等位置尚待逐一确认的陵群）
- 衣冠冢 / 纪念陵（成吉思汗陵）
- 边疆政权王陵（藏王墓、西夏王陵、辽陵、金陵）

未单独立点、只在「说明」里交代的：元代诸帝真陵（起辇谷）至今未发现；十六国、部分东汉 / 西晋 / 东晋帝陵位置未确认（以「陵区」示意）；南明、北元等流亡政权葬地多不可考。

## 数据说明

| 文件 | 用途 |
|---|---|
| `data/tombs.master.json` | 手工整理的原始数据（字段权威源） |
| `data/intros.json` | 每座陵的简介与到访提示 |
| `data/osm-matches.json` | 用 OpenStreetMap 公开数据校正后的坐标 |
| `data/baidu-refined.json` | 用百度地图 POI 反查补全的坐标（含 POI 名称与校正前偏差） |
| `data/routes.presets.json` | 17 条路线灵感 |
| `data/tombs.json` / `data/tombs.csv` | 构建产物（含合并后的坐标、简介），便于二次使用 |
| `js/data.tombs.js` / `js/data.routes.js` | 页面直接加载的数据（自动生成） |

**坐标精度**分三档：

- `high`：OpenStreetMap 实测或已确认的精确点位（当前 **86** 处，构建时自动统计）
- `mid`：百度地图 POI 反查补全（26 处，抽样与 OSM 对比偏差中位数约 300 米）或手工标注，误差约几公里以内
- `low`：陵区/位置待考，仅示意大致范围；页面会显示提示

坐标基准为 **WGS-84**。数据来源：OpenStreetMap（ODbL）实测点位 + 百度地图 POI 反查（经 BD09 墨卡托 → BD09 → GCJ-02 → WGS-84 转换）。高德底图使用 GCJ-02，渲染前由 `js/geo.js` 做标准偏移转换（含逆变换）。

数据维护流程：

```bash
# 修改 data/tombs.master.json / intros.json / osm-matches.json / baidu-refined.json / routes.presets.json 后：
node scripts/build-data.mjs
# 生成 js/data.tombs.js、js/data.routes.js、data/tombs.json、data/tombs.csv
```

## 文件结构

```
imperial-tombs/
├── index.html               # 页面骨架
├── css/app.css              # 全部样式（含移动端）
├── js/
│   ├── geo.js               # 纯几何/坐标工具（WGS↔GCJ、投影、距离、路线排序）
│   ├── map.js               # 零依赖地图引擎（瓦片 + Canvas 标注 + 聚类 + 交互）
│   ├── app.js               # 页面逻辑（筛选、行程、导出、弹窗）
│   ├── data.tombs.js        # 自动生成：帝陵数据
│   └── data.routes.js       # 自动生成：路线预设
├── data/                    # 原始与构建数据（见上表）
├── scripts/build-data.mjs   # 数据构建脚本
└── tests/                   # 零依赖测试（node 直接运行）
    ├── geo.test.mjs         # 投影/坐标转换/距离/路线排序
    └── map.zoom.test.mjs    # 地图引擎：滚轮/按钮/双击缩放、锚点、瓦片铺满、混合底图切换
```

没有构建步骤、没有 npm 依赖、没有 CDN：所有 JS/CSS 都在本地，`file://` 直接打开即可。

## 测试

```bash
node tests/geo.test.mjs        # 投影/坐标转换/距离/路线排序等纯逻辑（9 项）
node tests/map.zoom.test.mjs   # 地图引擎缩放/瓦片/混合底图回归（22 项）
```

`map.zoom.test.mjs` 用最小 DOM 桩在 `vm` 里直接跑 `js/map.js`，复现滚轮、按钮、双击、触控板累积滚动、`flyTo`、切底图与拖拽等手势，检查「每格恰好 ±1 级、鼠标下的地点不跑、视野不飞出中国、瓦片始终铺满视口、高倍 transform 不超限、混合底图按级切换」——2026-11 那次「一放大就白屏」的参数顺序 bug 就是被它兜住的。

## 底图与已知限制

- 里程与天数按**直线距离估算**（公路 ≈ 直线 × 1.32），不是真实路径规划；实际以高德导航为准。
- 「高德驾车路线」单次最多带 16 个途经点，站点更多时会截取前段，完整行程请用「复制行程」分段导航。
- 陵墓开放状态会变化，`status` 只是 2026 年整理时的参考，出行前请以景区 / 文物部门公告为准。
- 高德底图版权归高德；OSM 校正坐标遵循 ODbL。本项目仅作个人旅行规划与研究参考。
- 高德矢量瓦片在部分乡野 / 草原 / 荒漠地区没有 15 级以上的细节（会返回纯色空白瓦片），所以默认底图在 15 级起自动换用卫星影像；如需看道路编号可切回「高德 · 矢量」。
